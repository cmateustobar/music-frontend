# AGENTS.md — MUSIC APP FRONTEND

## Proyecto
Frontend de la aplicación Music App.

## Stack
- React
- Vite
- Tailwind CSS
- Capacitor

## Reglas de trabajo
1. Trabaja únicamente sobre el frontend.
2. No modificar el backend.
3. No modificar archivos fuera del proyecto.
4. No modificar .env.
5. No eliminar datos ni archivos sin autorización explícita.
6. Antes de modificar código, identifica únicamente los archivos necesarios.
7. Realiza cambios pequeños y focalizados.
8. No refactorizar código no relacionado con la tarea.
9. Mantener compatibilidad con la arquitectura y funcionalidades existentes.
10. Ejecutar únicamente las verificaciones necesarias después de los cambios.

## Dependencias
- No instalar paquetes si la tarea puede resolverse sin ellos.
- No actualizar dependencias por iniciativa propia.
- No modificar package-lock.json salvo que sea consecuencia necesaria de un cambio de dependencias.

## Build
- No generar dist o dev-dist salvo que la tarea lo requiera.
- No modificar archivos generados manualmente.

## Git
- Rama principal: main
- Remote: origin
- No hacer commit, push, eset, ebase ni operaciones destructivas sin autorización explícita.

## Seguridad
- Nunca exponer secretos ni valores de .env.
- No incluir credenciales en código, logs ni documentación.

## Objetivo
Priorizar soluciones simples, seguras, mantenibles y de bajo consumo de contexto.
